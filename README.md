# RV Industry Daily

A simple GitHub Pages site for a daily RV-industry briefing.

## Publish

Upload `index.html` and `styles.css` to the root of your `jbuttry.github.io` repository.

GitHub Pages should serve the site at:

https://jbuttry.github.io/

## Next phase

The layout is intentionally separated from the daily content so it can later be automated with GitHub Actions or another scheduled publishing workflow.
